How a level works

  1. Pick a blockEach block is one piece of Go: a go.mod line, a package clause, an import or a function.
  2. Stack it in a fileOrder matters. Blocks marked fixed stay put, and you build around them.
  3. Press RunThe terminal builds the module. Fix what it reports and run again.

Reading an error

When a build fails, the terminal prints one line per problem and the block at fault gets a red ring.

main.go:5:8: package animal is not in std
  • main.go is the file.
  • 5 is the line. Line numbers are printed beside every block.
  • 8 is the column, counted from the left.
  • The rest says what Go objects to.

Fenced off: internal/

A capital letter decides whether one name is visible. A directory called internal decides whether a whole package is. Only code in the directory that holds internal/, or deeper, may import what is inside.

Anything outside the fence gets use of internal package … not allowed. It calls an exported function of the parent package instead, here vault.Open. The concept “internal packages” puts this to work.

Controls

  • Mouse Drag a block into a file, or back onto the bin.
  • Touch Drag a block sideways into a file, or press and hold it for a moment to lift it and move it anywhere. Swiping up or down scrolls. You can also tap a block, then tap a dashed line.
  • Keyboard Tab to a block and press Enter to pick it up, then Tab to a dashed line and press Enter. Esc cancels, Delete sends the block back to the bin, Ctrl or Cmd + Enter runs.
  • Sound The button in the header turns it on or off.
